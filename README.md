## 📋 Summary

**PharmaVexa** is a modern web-based **Pharmacy Management System** designed to provide a centralized interface for managing pharmacy operations.

The application brings essential pharmacy modules together in one professional dashboard:

- 📊 Dashboard
- 💊 Medicines
- 📦 Inventory
- 🛒 Sales
- 📈 Analytics
- 🔔 Alerts
- ⚙️ Settings
- 👤 Profile

The project focuses on a clean user experience, responsive design, interactive navigation and pharmacy-focused data visualization.

## ✨ Key Features

### 📊 Dashboard
Centralized overview of important pharmacy information and statistics.

### 💊 Medicines
Dedicated medicine management interface for viewing medicine information.

### 📦 Inventory
Monitor pharmacy stock and inventory information.

### 🛒 Sales
Track sales, transactions, quantities and amounts.

### 📈 Analytics
Visualize pharmacy performance and business insights.

### 🔔 Alerts
Monitor important pharmacy alerts including:

- ⚠️ Low Stock
- 📦 Expiry Warning
- 🚨 Critical Stock

### 🌙 Dark / Light Mode
Switch between dark and light interface modes.

### 👤 Profile
Access administrator profile information.

### ⚙️ Settings
Manage application settings through a dedicated interface.

### 📱 Responsive Design
Designed for desktop and mobile screen sizes.
