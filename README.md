# 💊 PharmaVexa

### Intelligent Pharmacy Management System

PharmaVexa is a modern **Intelligent Pharmacy Management System** designed to provide a clean, fast and professional interface for managing pharmacy operations, medicines, inventory, sales and business analytics.

The project combines a futuristic **Neon Cyber-Pharmacy UI** with practical pharmacy management features to create a professional digital pharmacy experience.

---

## 📌 Project Summary

**PharmaVexa** is a web-based pharmacy management interface that brings important pharmacy operations into one centralized dashboard.

It provides dedicated sections for:

- 📊 Dashboard
- 💊 Medicines
- 📦 Inventory
- 🛒 Sales
- 📈 Analytics
- 🔔 Alerts
- ⚙️ Settings
- 👤 Profile

The main goal is to make pharmacy information easier to monitor through a modern dashboard, clear navigation, useful statistics and interactive UI components.

# 🚀 Main Features

### 📊 Dashboard
Centralized overview of pharmacy operations with important statistics and quick information.

### 💊 Medicines
Dedicated medicine management section for viewing and organizing medicine information.

### 📦 Inventory
Monitor available pharmacy stock and inventory-related information.

### 🛒 Sales
Track medicine sales, transactions, quantities and completed orders.

### 📈 Analytics
Provides business intelligence through:

- Revenue
- Orders
- Average Order Value
- Growth
- Weekly Sales
- Key Insights

### 🔔 Alerts
Displays important pharmacy notifications such as:

- Low Stock
- Expiry Warning
- Critical Stock

### ⚙️ Settings
Dedicated settings section for application configuration.

### 👤 Profile
Professional user profile interface for the pharmacy administrator.

### 🌙 Dark / Light Mode
Theme switching functionality for a better user experience.

### 🔔 Interactive Notifications
Notification panel provides quick access to important pharmacy alerts.

### 🧭 Interactive Navigation
Sidebar navigation allows quick movement between different pharmacy modules.
