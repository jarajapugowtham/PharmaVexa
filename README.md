# 💊 About the Project

**PharmaVexa** is an **Intelligent Pharmacy Management System** designed to provide a modern digital interface for managing and monitoring pharmacy operations.

The application combines:

- Pharmacy management
- Medicine management
- Inventory monitoring
- Sales tracking
- Business analytics
- Pharmacy alerts
- User profile management
- Application settings

into one centralized dashboard.

The project focuses on creating a professional, responsive and user-friendly pharmacy management experience.
