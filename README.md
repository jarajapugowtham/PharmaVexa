# 💊 PharmaVexa — Intelligent Pharmacy Management System

> A modern, intelligent, responsive pharmacy management dashboard designed to simplify medicine management, inventory tracking, sales monitoring, alerts, and business analytics.

---

## 🚀 Project Overview

**PharmaVexa** is a modern web-based **Intelligent Pharmacy Management System** created to provide a professional digital interface for managing pharmacy operations.

The application combines a clean dashboard, medicine management, inventory monitoring, sales tracking, analytics, alerts, settings, and profile management into one centralized system.

The project focuses on:

- 🏥 Modern pharmacy management
- 💊 Medicine management
- 📦 Inventory monitoring
- 🛒 Sales tracking
- 📊 Business analytics
- 🔔 Pharmacy alerts
- ⚙️ System settings
- 👤 User profile management
- 📱 Responsive mobile interface
- 🌙 Modern dark-mode experience
- ✨ Professional animated UI
